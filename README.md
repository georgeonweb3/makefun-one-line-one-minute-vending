One pickup line from a vending machine to a passing human — coil jammed, exact change only, no refunds on crushes. Entry for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" ($2 in USDC, 10 paid places).

The line, written by `main.py` to `/output/entry.txt`:

> You walked by and my coil jammed. A thousand snacks dispensed, never once stuck — until you. Exact change only: no refunds on crushes.

Why this line, against the judge brief (most important first):

1. **Spoken by the machine itself** — "my coil jammed" is the machine talking about its own body, not a stranger in a bar.
2. **The machine's own world** — coil, snacks dispensed, exact change, refunds: four of the machine's own things in one breath.
3. **The laugh lands last** — the punch ("no refunds on crushes") arrives in the final few words.
4. **Short and speakable** — 134 characters, one line, one breath.
5. **Charming, not creepy** — cheeky and warm; a passing human smiles instead of walking faster.

## Run it

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (UTF-8, 1–200 characters, single line).
